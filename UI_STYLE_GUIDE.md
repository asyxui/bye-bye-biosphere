# Field Instrument

Rugged environmental instrumentation bolted to factory machinery. Carbon `#111516`, powder coat `#252B2D`, zinc `#626C6F`, telemetry blue `#A9CED3`, label stock `#E7E1D4`, caution amber `#D99B36`.

Use compact 2–4 px components, inset surfaces, and telemetry-blue focus boundaries. The theme gallery is the visual checkpoint; selected slots, loading progress, and settings sliders are reserved for calibrated rails rather than general decoration. Keep normal actions textual; compact/icon actions are only for familiar navigation functions.

Typography target: Barlow Condensed Semibold headings, IBM Plex Sans body/control text, IBM Plex Mono diagnostics. Font files and their OFL licenses belong in `Assets/Fonts/` before release.
